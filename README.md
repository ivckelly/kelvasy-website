# Kelvasy website (kelvasy.com)

Static site: index.html + logo.png. No build step.

## Deploy
1. Push this folder to a GitHub repo (e.g. kelvasy-website), root of repo = these files.
2. Import the repo on Vercel / Netlify / Cloudflare Pages (framework: None, no build command, output dir: root).
3. Add domains kelvasy.com and www.kelvasy.com in the host's Domains settings and add the DNS records it shows.
4. IMPORTANT: do NOT change or delete the existing DNS record for app.kelvasy.com (the live system).
